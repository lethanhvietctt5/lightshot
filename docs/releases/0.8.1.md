## Highlights

Lightshot 0.8.1 has a new app icon.

**New icon**
- The icon is now a blue tile with capture brackets around a photo. You'll see it in Finder and Launchpad, and in the Dock and the app switcher while the editor is open.
- The menu-bar icon is unchanged.
- If you still see the old icon after the update, quit Lightshot and open it again; macOS caches app icons.

Nothing else changes in this release.

Redaction reminder: only **blackout** erases pixels. Blur and pixelate only obscure, so don't rely on them to hide secrets.
