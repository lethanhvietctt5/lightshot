## Highlights

Lightshot 0.8.2 fixes OCR Text getting stuck on "Reading text…".

**OCR Text no longer waits on "Reading text…"**
- The first OCR Text after installing, or after a macOS update, could sit on "Reading text…" for about half a minute while macOS prepared its text-recognition models. Lightshot now prepares them in the background when it starts, so the first OCR is as quick as the rest.
- Auto Redact's first scan is quick for the same reason.
- Fixed a rare hang where text recognition could stop answering until Lightshot was restarted.

Nothing else changes in this release.

Redaction reminder: only **blackout** erases pixels. Blur and pixelate only obscure, so don't rely on them to hide secrets.
