## Highlights

The first release of Lightshot: a local-only, CleanShot-style screenshot tool for macOS 14 and later. Everything runs on your Mac — no cloud, no accounts, no network.

**Capture**
- Area capture with a drag-to-select overlay, live pixel dimensions, and adjustable edges.
- Window capture with hover highlight — click a window to grab it.
- Fullscreen capture of any display.
- Self-timer, cursor inclusion, repeat-last-capture, and multi-display selection.
- Rebindable global hotkeys, and a CleanShot-style menu-bar menu with icons and live shortcuts.

**Annotate**
- Arrows (CleanShot-parity styles), lines, rectangles, ellipses, freehand strokes, text, highlights, and auto-numbered step markers.
- Crop that is adjustable and reversible; full undo/redo.
- Redaction: **blackout** erases pixels and is the only option safe for secrets. Blur and pixelate only obscure — do not rely on them to hide sensitive data.
- The drawing tool stays active between shapes; bigger default sizes; type an exact font size.

**Finish**
- The editor opens the moment you release a selection; ⌘S copies to the clipboard.
- Copy, save as PNG/JPEG (with quality), drag out, or **pin** the shot as a floating always-on-top window.
- Local capture history with reopen, reveal in Finder, delete, and configurable retention.
- Open an existing image file in the editor.

**Setup**
- Guided first-run onboarding for Screen Recording, with recovery when the permission is revoked.
- Settings for hotkeys, defaults, and launch at login.
